# Student Management System

## Project Overview

The Student Management System is a Java Full Stack project used to manage student information.

## Features

- Add Student
- View Student
- Update Student
- Delete Student

## Technologies Used

- Java
- JDBC
- MySQL
- HTML
- CSS
- JavaScript

## Project Structure

- Frontend – User Interface
- Backend – Java Application
- JDBC – Database Connectivity
- Database – MySQL
- Screenshots – Project Output

## How to Run

1. Open the project in a Java IDE.
2. Configure the MySQL database.
3. Configure the JDBC connection.
4. Run the application.
